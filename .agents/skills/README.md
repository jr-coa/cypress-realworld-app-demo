# Project skills

These skills are adapted for `jr-coa/cypress-realworld-app-demo`. The current checkout is `/workspace/cypress-realworld-app`;
the project delivery branch is `develop`. Select `develop` when creating a fresh environment.

| Skill                                               | Use it for                                                                                                                                  |
| --------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| [cloud-development](cloud-development/SKILL.md)     | Installing, starting, and validating the cloud development environment; Playwright MCP screenshots and recordings.                          |
| [cloud-task-delivery](cloud-task-delivery/SKILL.md) | Taking a Slack-origin engineering task through a fork PR, iteration, environment-specific verification, and results in the original thread. |
| [create-pr](create-pr/SKILL.md)                     | Preparing scoped changes and opening a draft PR against the fork.                                                                           |
| [code-review](code-review/SKILL.md)                 | Reviewing a local diff or GitHub PR, submitting an explicitly requested review, or addressing review feedback.                              |
| [writing-tests](writing-tests/SKILL.md)             | Writing or changing this project's Vitest, Cypress component, API, and UI tests.                                                            |

Editing or installing these skills does not create commits, push a branch, open a PR, or post a
review. Those actions belong to the corresponding user-requested workflow.
